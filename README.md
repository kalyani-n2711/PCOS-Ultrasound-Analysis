
# PCOS Ultrasound Image Analysis using Python

This project focuses on the analysis of ultrasound images and clinical data
to identify structural and statistical differences between PCOS and non-PCOS ovaries.

## 📌 Features
- Ultrasound image preprocessing (cropping, augmentation)
- Edge detection and contour analysis using OpenCV
- Pixel intensity comparison (Normal vs PCOS)
- Heatmap visualization and follicle overlay
- Conversion of image data into DataFrame
- Exploratory Data Analysis (EDA) on clinical dataset

## 🛠️ Tools & Libraries
- Python
- NumPy, Pandas
- Matplotlib, Seaborn
- OpenCV
- Google Colab

## 📂 Dataset
- Ultrasound images from Kaggle (Normal & PCOS)
- Clinical dataset with hormonal, BMI, and lifestyle parameters

## 📊 Results
- PCOS ovaries show higher pixel intensity variation
- Dense follicle clustering observed in PCOS cases
- Clear visual differentiation using heatmaps and overlays
